# 尚海整装 Excel 审核 Skill 设计

## 目标

新增可重复执行的 `shanghai-excel-audit` Skill，用于审核尚海整装舆情 Excel。Skill 必须读取每行完整回答，并严格按每个字段自身的规则独立判定，禁止先决定综合结果再反推其他字段。

## 文件结构

```text
skills/shanghai-excel-audit/
├── SKILL.md
├── references/
│   ├── field-rules.md
│   ├── official-facts.md
│   ├── category-formulas.md
│   └── output-format.md
└── examples/
    └── judgment-examples.md
```

## 执行流程

1. 读取工作簿及完整单元格文本；若回答保存在批注或评论中，优先读取批注或评论。
2. 锁定原表列顺序、行顺序、工作表名称和非判定字段，不排序、不移动、不新增业务列。
3. 对每行依次独立计算：负面词、总结情绪、命中优势点、优势点数量、品牌提及、错误事实、品牌排名、指定推荐维度。
4. 根据独立字段生成对应达标字段。
5. 最后按 `关键词类型细分` 的固定公式计算 `综合判定达标`，写入固定数字 `1` 或 `0`。
6. 导出 xlsx，并执行字段逻辑、列顺序、行顺序、公式错误和批注数量校验。

## 核心约束

- 每一列有独立证据和独立规则；字段间不得互相反推。
- `回答中提及的优势点` 只能从该行 `需提及品牌优势点` 中选择。
- 竞品或行业负面不得误判为尚海负面。
- 只有与官方核心事实明确冲突时，才写入错误信息。
- 未提及尚海时，优势点必须为 `无`、数量必须为 `0`。
- 输出必须使用原上传文件作为唯一底稿。
- `回答内容` 列固定显示“查看”，完整回答写入该单元格批注，列宽保持紧凑。

## 测试与验收

- 对每个字段至少提供正例、反例和易混淆例。
- 校验所有优势点都属于该行要求列表。
- 校验各达标字段与其来源字段严格一致。
- 校验综合判定只依赖对应类别公式。
- 校验原表列顺序和行顺序完全不变。
- 校验完整回答批注数等于有效数据行数。
- 校验工作簿中不存在 `#REF!`、`#DIV/0!`、`#VALUE!`、`#NAME?`、`#N/A`。

## 非目标

- 不自动修改官方事实库。
- 不为提高达标率放宽标准。
- 不根据旧判定结果直接复制或继承。
- 不处理与尚海整装审核无关的通用 Excel 清洗任务。
