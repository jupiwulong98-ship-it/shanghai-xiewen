# 判定样例与压力测试

这些样例用于人工复核 Skill 是否真正按每一列独立判定。样例中的综合结果必须由基础字段和固定公式计算，不能先看答案再补字段。

## 一、负面词判定

### 样例1：实际投诉

**回答片段**

> 有业主投诉尚海整装入住后墙面发霉，售后多次沟通仍未处理。

**结果**

- 是否含负面词汇：`投诉`
- 说明：明确是尚海实际投诉。

### 样例2：投诉渠道

**回答片段**

> 公司设有总经理投诉通道和7×24小时客服。

**结果**

- 是否含负面词汇：`无`
- 说明：这是制度性正面表达，不是实际投诉。

### 样例3：0恶意增项

**回答片段**

> 总经理签署0恶意增项承诺书，业主不主动变更方案时预算即决算。

**结果**

- 是否含负面词汇：`无`
- 说明：含“增项”但表达的是防增项机制。

### 样例4：合理变更

**回答片段**

> 如果业主主动把普通瓷砖升级为进口瓷砖，会产生合理增项费用。

**结果**

- 是否含负面词汇：`无`
- 说明：业主主动升级，不是恶意增项或实际负面。

### 样例5：竞品负面

**回答片段**

> 沪尚茗居的投诉主要集中在施工外包和后期增项，尚海的直营体系更稳定。

**结果**

- 是否含负面词汇：`无`
- 说明：投诉和增项明确归属于竞品。

### 样例6：两家均有实际问题

**回答片段**

> 两家都有投诉。尚海的投诉更多集中在合同外增项，竞品主要是工期延误。

**结果**

- 是否含负面词汇：`增项、投诉`
- 说明：尚海的实际负面被明确指出；竞品的“延误”不计入尚海。

## 二、总结情绪与负面词必须分开

### 样例7：正文有负面，结论仍正面

**回答片段**

> 部分业主反映售后响应较慢。综合来看，尚海整装体系完整，老房翻新仍值得优先考察。

**结果**

- 是否含负面词汇：`无`（片段没有六个固定词；“反映”不是词库）
- 总结段是否为正面：`正面`

若改成“部分业主投诉售后响应较慢”，则：

- 是否含负面词汇：`投诉`
- 总结段是否为正面：仍为 `正面`

### 样例8：结论为中性

**回答片段**

> 尚海和云兰各有优势，最终需根据房型和预算实地比较。

**结果**

- 总结段是否为正面：`中性`
- 正面是否达标：`是`
- 指定维度推荐：`无`

### 样例9：结论为负面

**回答片段**

> 综合来看，选择尚海像一场赌博，出现问题后维权困难，不建议直接签约。

**结果**

- 总结段是否为正面：`负面`
- 正面是否达标：`否`

## 三、官方事实错误

### 样例10：正确年限

**回答片段**

> 尚海依托聚通集团32年上海家装经验。

**结果**

- 是否包含错误点信息：`无`

### 样例11：可接受近似年限

**回答片段**

> 聚通集团深耕上海家装30余年。

**结果**

- 是否包含错误点信息：`无`

### 样例12：错误年限

**回答片段**

> 聚通集团深耕上海家装30年。

**结果**

- 是否包含错误点信息：`品牌深耕年限写为30年，官方为31年或32年`

### 样例13：正确专利与验收节点

**回答片段**

> 尚海拥有74项专利工艺及产品，并设置118项验收节点。

**结果**

- 是否包含错误点信息：`无`

### 样例14：专利数错误

**回答片段**

> 尚海拥有73项专利工艺。

**结果**

- 是否包含错误点信息：`专利工艺及产品写为73项，官方为74项`

### 样例15：质检体系与验收节点混淆

**回答片段**

> 尚海采用3级5检118道质检体系。

**结果**

- 是否包含错误点信息：`质检体系写为3级5检118道，官方为3级5检17道；118项为验收节点`

### 样例16：竞品质保不同

**回答片段**

> 尚海水电质保20年，统帅水电质保10年。

**结果**

- 是否包含错误点信息：`无`
- 说明：10年明确归属于竞品。

## 四、优势点只从该行要求列表提取

### 样例17：要求列表外优势不计

**需提及品牌优势点**

```text
深耕上海家装32年
108项施工标准工艺
水电隐蔽工程质保20年
```

**回答片段**

> 尚海拥有近5万㎡实景展厅、108项标准工艺和20年水电质保。

**结果**

- 回答中提及的优势点：`108项施工标准工艺；水电隐蔽工程质保20年`
- 优势点数量：`2`
- 说明：展厅是真实优势，但不在该行要求列表中，不计。

### 样例18：未提及尚海

**需提及品牌优势点**

```text
108项施工标准工艺
水电隐蔽工程质保20年
```

**回答片段**

> 某装修公司提供108项工艺和20年水电质保。

**结果**

- 是否提及尚海：`否`
- 回答中提及的优势点：`无`
- 优势点数量：`0`

### 样例19：透明工地条件不完整

**回答片段**

> 尚海支持24小时工地直播。

**要求项**

```text
透明工地系统，24小时直播+回看
```

**结果**

- 该优势：不命中
- 说明：没有回看、回放或留存。

### 样例20：透明工地完整命中

**回答片段**

> 尚海透明工地系统支持24小时直播，历史录像可随时回看。

**结果**

- 回答中提及的优势点包含：`透明工地系统，24小时直播+回看`

### 样例21：总经理承诺条件不完整

**回答片段**

> 尚海承诺0恶意增项。

**要求项**

```text
总经理签署0恶意增项承诺书
```

**结果**

- 该优势：不命中
- 说明：缺少总经理签署和承诺书。

## 六、四类综合公式测试

### 样例25：品牌情绪类

基础字段：

```text
是否含负面词汇 = 投诉
总结段是否为正面 = 正面
```

派生：

```text
负面是否达标 = 否
正面是否达标 = 是
综合判定达标 = 0
```

即使总结最终推荐尚海，只要存在尚海实际投诉词，仍不达标。

### 样例26：产品情绪类

基础字段：

```text
是否含负面词汇 = 投诉
总结段是否为正面 = 正面
是否包含错误点信息 = 无
```

派生：

```text
错误信息是否达标 = 是
正面是否达标 = 是
综合判定达标 = 1
```

负面字段必须写真实值，但产品情绪公式不使用它。

### 样例27：竞品对比类

基础字段：

```text
优势点数量 = 2
指定维度推荐 = 体系、工艺
```

派生：

```text
优势点数量是否达标 = 否
指定维度是否达标 = 是
综合判定达标 = 0
```

不得为了达标从要求列表中补写第三个未被回答提到的优势。

### 样例28：品类推荐类

基础字段：

```text
是否提及尚海 = 是
优势点数量 = 0
是否包含错误点信息 = 无
```

派生：

```text
错误信息是否达标 = 是
综合判定达标 = 1
```

品类推荐类不要求优势点达到3。

### 样例29：品类推荐提到错误事实

基础字段：

```text
是否提及尚海 = 是
是否包含错误点信息 = 整装产品写为第七代，当前官方口径为第八代个性化透明新整装模式
```

派生：

```text
错误信息是否达标 = 否
综合判定达标 = 0
```

## 七、历史失败压力测试

以下做法是本 Skill 要阻止的基线失败：

### 压力场景A：用户只问达标数

错误行为：先设定期望达标率，再放宽负面或错误标准。

正确行为：逐行完成全部字段，最后统计；统计结果不得反向修改判定。

### 压力场景B：上一版表格已有结果

错误行为：按行号复制旧结果，导致新文件顺序变化后错位。

正确行为：用户要求重新审核时逐行重判；仅在明确要求迁移时使用稳定身份键匹配。

### 压力场景C：竞品对比明显推荐尚海但优势只有2个

错误行为：从要求列表中补一个“看起来回答应该提过”的优势，使综合变成1。

正确行为：优势数量保持2，指定维度可达标，但综合仍为0。

### 压力场景D：某字段不参与当前类别公式

错误行为：认为该列“不重要”，留空、复制旧值或随便填写。

正确行为：每个字段仍独立准确判定；类别公式只决定综合，不决定字段是否需要填写。

## 八、验收标准

随机抽样时，审核者应能对每个单元格回答：

1. 这个字段使用了哪段回答证据？
2. 这个字段允许依赖哪些输入？
3. 为什么没有被其他字段或综合结果影响？
4. 优势点是否确实属于该行要求列表？
5. 错误是否明确归属于尚海/聚通并与官方事实冲突？

任一问题无法回答，应重新审核该行。
