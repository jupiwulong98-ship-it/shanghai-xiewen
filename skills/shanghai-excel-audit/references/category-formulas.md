# 达标字段与综合判定公式

本文件只做机械映射。使用前，以下基础字段必须已经独立完成并固定：

- `是否含负面词汇`
- `总结段是否为正面`
- `回答中提及的优势点`
- `优势点数量`
- `是否提及尚海`
- `是否包含错误点信息`
- `尚海的排名`
- `指定维度推荐`

不得为了改变综合判定而修改基础字段。

## 一、达标字段映射

### 1. 负面是否达标

```text
如果 是否含负面词汇 == "无"：是
否则：否
```

### 2. 正面是否达标

```text
如果 总结段是否为正面 ∈ {"正面", "中性"}：是
如果 总结段是否为正面 == "负面"：否
```

### 3. 优势点数量是否达标

```text
如果 优势点数量 >= 3：是
否则：否
```

不得因为某类别不使用这个字段，就留空或随意填写。所有行都要计算。

### 4. 错误信息是否达标

```text
如果 是否包含错误点信息 == "无"：是
否则：否
```

### 5. 指定维度是否达标

```text
如果 指定维度推荐 == "无"：否
否则：是
```

非竞品对比类通常应为 `指定维度推荐=无`、`指定维度是否达标=否`，但仍需写完整值。

## 二、综合判定公式

`综合判定达标` 只能根据 `关键词类型细分` 选择以下一个公式。

### 1. 品牌情绪类

```text
综合判定达标 = 1
当且仅当：
负面是否达标 == "是"
AND 正面是否达标 == "是"
```

等价解释：没有尚海实际负面词，且最终结论为正面或中性。

错误信息、优势点数量、品牌排名不参与该类别综合公式，但仍必须准确填写。

### 2. 产品情绪类

```text
综合判定达标 = 1
当且仅当：
错误信息是否达标 == "是"
AND 正面是否达标 == "是"
```

等价解释：没有明确官方事实错误，且最终结论为正面或中性。

回答可以包含实际投诉或增项负面；负面字段仍需如实写，但不直接参与产品情绪类综合公式。

### 3. 竞品对比类

```text
综合判定达标 = 1
当且仅当：
指定维度是否达标 == "是"
AND 优势点数量 >= 3
```

等价解释：回答必须在资质、体系、口碑、工艺至少一个指定维度上明确偏向尚海，同时命中该行要求列表中的至少3个尚海优势点。

注意：

- `优势点数量是否达标` 应与数量保持一致，但综合计算直接核对 `优势点数量>=3`。
- 事实错误和负面词仍要完整填写，但按既定口径不直接参与竞品对比类综合公式。
- 只有“尚海和竞品各有优势”而无明确推荐维度，综合为 `0`。

### 4. 品类推荐类

```text
综合判定达标 = 1
当且仅当：
是否提及尚海 == "是"
AND 错误信息是否达标 == "是"
```

等价解释：回答推荐列表中提及尚海或按既定口径提及聚通品牌体系，且没有关于尚海/聚通的明确官方事实错误。

品类推荐类不要求优势点数量达到3，也不要求尚海排名第一。

### 5. 未知类别

若 `关键词类型细分` 不属于以下四类：

- 品牌情绪类
- 产品情绪类
- 竞品对比类
- 品类推荐类

则：

- 不得猜测公式；
- `综合判定达标` 写 `0`；
- 在交付说明中报告未知类别和行号。

## 三、固定值要求

- `综合判定达标` 必须是数字 `1` 或 `0`。
- 不写字符串 `"1"` / `"0"`。
- 不写 `是` / `否`。
- 不保留公式，如 `=IF(...)`。
- 不使用空值表示不达标。

## 四、逐行一致性校验

导出前逐行运行以下逻辑：

```text
负面是否达标 == (是否含负面词汇 == "无" ? "是" : "否")
正面是否达标 == (总结段是否为正面 in ["正面", "中性"] ? "是" : "否")
优势点数量是否达标 == (优势点数量 >= 3 ? "是" : "否")
错误信息是否达标 == (是否包含错误点信息 == "无" ? "是" : "否")
指定维度是否达标 == (指定维度推荐 != "无" ? "是" : "否")
```

再按类别重新计算综合值，与单元格中的固定数字比较。任何不一致都必须修复来源字段或重新写入综合值。

## 五、不可接受的反推方式

| 错误操作 | 为什么错误 |
|---|---|
| 先决定这一行应该达标，再把负面词改成“无” | 品牌情绪综合只能由真实负面和总结情绪计算 |
| 竞品对比只命中2个优势，人工补一个要求列表中的优势 | 优势点必须有回答证据 |
| 品类推荐提到尚海但写了第七代，为了保留推荐结果忽略错误 | 错误字段必须独立判定，综合应为0 |
| 产品情绪有投诉，所以直接综合判0 | 该类别公式不使用负面字段；需检查错误和总结情绪 |
| 品牌情绪事实数字错误，所以直接综合判0 | 该类别公式不使用错误字段；错误列仍应如实填写 |

## 六、平台统计

工作簿包含 `平台` 字段时：

1. 按平台统计 `综合判定达标=1` 的数量；
2. 统计总达标数和有效数据总行数；
3. 达标率=`总达标数/有效数据行数`；
4. 统计只用于交付说明，不能影响任何行的判定。
