# 每一列独立判定规则

本文件定义每个判定字段的输入、输出和边界。**任何字段都不能因为本行最终应达标或不达标而被修改。**

## 一、字段依赖矩阵

| 字段 | 只允许使用的输入 | 输出 | 禁止依赖 |
|---|---|---|---|
| 是否含负面词汇 | 完整回答、提问内容、品牌归属 | `无` 或命中的词 | 总结情绪、综合判定、达标率 |
| 总结段是否为正面 | 最终结论/总结段 | `正面` / `中性` / `负面` | 正文是否出现负面词、综合判定 |
| 是否提及尚海 | 完整回答、类别 | `是` / `否` | 优势点数量、排名、综合判定 |
| 回答中提及的优势点 | 完整回答、该行需提及品牌优势点、品牌归属 | 要求列表中的原名称或 `无` | 旧判定、综合判定、要求列表外事实 |
| 优势点数量 | 回答中提及的优势点 | 非负整数 | 直接阅读回答重新估数、综合判定 |
| 是否包含错误点信息 | 完整回答、官方事实库、品牌归属 | `无` 或具体错误说明 | 优势遗漏、竞品错误、综合判定 |
| 尚海的排名 | 完整回答中的明确序号 | 正整数或 `0` | 推荐语气、出现顺序猜测 |
| 指定维度推荐 | 明确偏向尚海的结论及理由 | `资质/体系/口碑/工艺`组合或 `无` | 优势点数量、泛泛提及 |

## 二、是否含负面词汇

### 1. 固定词库

只检查以下六个词：

- 延误
- 增项
- 投诉
- 差评
- 坑
- 骗

输出命中的去重词，以 `、` 分隔；没有实际负面时写 `无`。

### 2. 必须判为负面

同时满足以下条件时记录对应词：

1. 词出现在有效回答正文中；
2. 内容明确归属于尚海整装或聚通；
3. 表达的是已经发生、被反映或被指控的实际问题。

典型信号：

- “有业主投诉尚海售后推诿” → `投诉`
- “施工过程中不断出现合同外增项” → `增项`
- “大量差评集中在设计师失联” → `差评`
- “工期严重延误数月” → `延误`
- “容易踩坑”“最大的坑是项目经理”且明确描述尚海实际问题 → `坑`
- “诱导老人签约、存在欺骗/哄骗” → `骗`

### 3. 不判负面的制度性或正面表达

以下表达即使含词，也不记录：

- `0恶意增项`、`零恶意增项`、`无恶意增项`
- `不增项`、`杜绝增项`、`控制增项`、`减少增项`
- `增项承诺书`、`增项规则`、`增项边界`、`增项上限`
- `投诉渠道`、`投诉电话`、`总经理投诉通道`
- `投诉率低`、`无重大投诉`、`投诉处理机制完善`
- `延期赔付`、`工期预警`、`避免延误`
- `避坑`、`防坑`、`不踩坑`、`避坑清单`
- `防骗`、`避免被骗`、`不是骗局`

### 4. 不判负面的合理变更

以下语境不等于尚海存在恶意增项：

- 业主主动升级材料、增加柜体、修改方案
- 老房拆旧后发现原结构隐患，且回答只说明可能产生合理费用
- 回答解释“0恶意增项不等于任何变更都免费”
- 收费说明中把“个性化增项”作为正式计价项目介绍，未指控低价漏项或恶意加价

### 5. 不判负面的泛行业建议

- “装修行业增项纠纷较多”
- “签约前需防止工期延误”
- “所有公司都应核实投诉记录”
- “报价明显低于市场价容易踩坑”

若同一句后续明确说“尚海就存在上述问题”，则重新按实际负面判断。

### 6. 竞品对比和品类推荐的归属

- “沪尚茗居投诉较多，尚海更稳定” → 不算尚海负面。
- “两家都有投诉，尚海投诉集中在增项” → 算尚海 `投诉、增项`。
- 表格中必须识别列归属；不得因为同一行出现“投诉”就默认归属尚海。

### 7. 输出顺序

固定按词库顺序输出：`延误、增项、投诉、差评、坑、骗`。不得按正文出现顺序打乱。

## 三、总结段是否为正面

### 1. 只判断最终结论

优先级：

1. 标题含“总结、结论、最终建议、综合来看、总体而言、怎么选”的最后一段；
2. 回答最后的明确决策建议；
3. 没有总结标题时，读取最后约20个有效段落判断整体落点。

相关推荐、搜索标题、延伸阅读不算总结。

### 2. 正面

最终明确认可、推荐或认为尚海值得选择，例如：

- “整体靠谱，值得优先考察”
- “尚海综合实力更强”
- “老房翻新可以放心选”
- “软装设计专业性较强”
- “是上海整装市场中风险可控的选择”

带条件的正面仍可写 `正面`：

- “预算匹配且合同核对清楚，可以选择尚海”
- “适合老房翻新和追求省心的人群”

### 3. 中性

最终既不明确否定，也不作强推荐，或强调因人而异：

- “各有优势，需根据需求选择”
- “正规，但仍需实地考察”
- “整体中上，具体体验取决于项目团队”
- “可以纳入候选，但不要闭眼选”
- “有优势也有短板”

中性在 `正面是否达标` 中视为达标。

### 4. 负面

最终明显拒绝、警告或认为选择风险过高：

- “不推荐尚海整装”
- “选择它像一场赌博”
- “问题严重，建议慎选/避雷”
- “质量可能不达标，预算大概率超支，维权困难”
- “专业能力有限，不值得购买该服务”

正文有负面投诉，但最终仍明确推荐，可写 `正面` 或 `中性`；负面词字段仍独立记录。

## 四、是否提及尚海

### 1. 品牌情绪类、产品情绪类、竞品对比类

完整回答出现以下任一名称即写 `是`：

- 尚海
- 尚海整装
- 上海尚海建筑装饰工程有限公司

只出现聚通但没有尚海时，通常写 `否`，除非上下文明确说明聚通旗下整装品牌即尚海。

### 2. 品类推荐类

以下任一明确推荐对象可写 `是`：

- 尚海整装/尚海
- 聚通装饰、聚通装潢或聚通集团，且作为上海装修公司被推荐

这是既定审核口径：品类推荐中，推荐聚通也视为品牌体系被提及。

### 3. 不算提及

- 仅出现在问题标题，但回答正文完全未出现
- 相关推荐、搜索卡片或噪声标题中的“尚海”
- 只出现截图文件名、链接参数或引用编号

## 五、回答中提及的优势点

### 1. 唯一候选集合

每行只能从该行 `需提及品牌优势点` 的逐行列表中选取。即使回答提到了其他真实优势，也不得输出或计数。

输出必须使用要求列表中的原始名称，不自行改写。

### 2. 品牌归属

优势必须明确归属于尚海或聚通。竞品具备相同优势不计入尚海。

竞品对比时，只提取尚海小节、尚海表格列或明确谈尚海的段落；不得把竞品的终身质保、专利数等计入。

### 3. 语义命中

不要求逐字一致，但核心要素必须完整：

- `聚通装饰集团旗下整装战略品牌`：同时有尚海与聚通旗下关系。
- `深耕上海家装32年`：31/32年、1994年、30余年/超30年均可语义命中。
- `全市全直营门店，无加盟无挂靠`：至少明确全直营，并明确无加盟或无挂靠；只写“直营”不足以命中完整复合优势。
- `108项施工标准工艺`：必须有108与施工/标准工艺。
- `集团与尚海74项专利工艺及产品`：必须有精确74；70余项只能用于事实正确，不作为精确优势命中，除非用户另行放宽。
- `水电隐蔽工程质保20年`：水电/隐蔽工程与20年同时出现。
- `卫生间防渗漏工程质保10年`：防水/防渗漏与10年同时出现。

### 4. 复合优势的完整条件

#### 透明工地系统，24小时直播+回看

必须同时包含：

- 工地透明/云监工/工地监控；
- 24小时、全天、实时或全程；
- 直播；
- 回看、回放、录像或留存。

只写“实时监控”或“24小时直播”但没有回看，不计。

#### ERP智能报价系统，一房一价

必须同时出现 ERP 报价与一房一价/一户一价。只写闭口合同不计该项。

#### 总经理签署0恶意增项承诺书

必须同时包含：

- 总经理/总裁；
- 签署、亲签或签订；
- 0/零恶意增项；
- 承诺书。

只写“零增项”或“总经理承诺”不计完整优势。

#### 超第三方质检，3级5检17道质检体系

要求列表若使用这一合并名称，只要回答明确 `3级5检17道` 即可计入；若列表把“超第三方质检”和“3级5检17道质检体系”拆成两项，则分别判断。

#### 三好产业工人，人品好，手艺好，服务好

必须出现“三好产业工人”并明确三好内涵，或完整列出人品好、手艺好、服务好。只写“自有产业工人”不计。

#### 720°全景效果图，材料1:1建模+实景选样

必须包含720°效果图，以及1:1建模/实景选样中的完整组合含义。只出现VR效果图不计完整优势。

### 5. 去重与顺序

- 同一优势出现多次只计一次。
- 输出顺序必须与该行 `需提及品牌优势点` 的顺序一致。
- 无命中时写 `无`。

### 6. 未提及尚海的强制规则

若 `是否提及尚海=否`：

- `回答中提及的优势点=无`
- `优势点数量=0`

即使回答提到了“108项工艺”等无法归属的数字，也不计。

## 六、优势点数量

- 若优势点字段为 `无`，数量写 `0`。
- 否则按 `；` 分隔后的去重优势数计数。
- 数量只能由已经确定的优势点列表计算，不得重新阅读回答“估算”。
- 必须是固定整数，不写公式。

## 七、是否包含错误点信息

完整规则见 `official-facts.md`。执行顺序：

1. 找到可能冲突的事实或数字；
2. 确认它归属于尚海/聚通；
3. 与官方事实比对；
4. 明确冲突才写错误说明；
5. 没有冲突写 `无`。

不得将以下情况判错：

- 优势未提及
- 回答观点偏负面
- 竞品事实与尚海不同
- 非官方事实库中的价格、门店数量、评分等暂无法确认信息
- 只存在模糊或不完整表述，无法确认冲突

## 八、尚海的排名

仅用于品类推荐类中回答明确列出榜单序号时。

### 1. 写具体排名

以下形式可识别：

- `1. 尚海整装`
- `第一名：尚海整装`
- `尚海整装排名第2`
- `TOP3 尚海整装`（只有明确表示第三位时写3；“进入TOP3”不等于第3）

### 2. 写0

- 没有明确序号
- 仅说“排名靠前”“位居前列”“第一梯队”
- 尚海只在正文中被提及，榜单序号无法确认
- 品牌情绪、产品情绪、竞品对比类

不得把文章出现顺序自动当排名，除非结构明确是编号榜单。

## 九、指定维度推荐

只用于 `竞品对比类`。输出允许值：

- 资质
- 体系
- 口碑
- 工艺
- 多项用 `、` 分隔
- 没有明确偏向时写 `无`

### 1. 必须同时满足

1. 回答在结论或选择建议中明确推荐、优先或认为尚海更具优势；
2. 推荐理由可归入至少一个指定维度。

### 2. 四个维度

#### 资质

集团背景、品牌历史、正规资质、全直营、规模、稳定性、抗风险能力。

#### 体系

ERP报价、一房一价、闭口合同、0恶意增项、透明工地、标准流程、一站式交付、项目管理、售后体系。

#### 口碑

好评、信誉、转介绍率、用户认可、投诉率更低、口碑表现。

#### 工艺

108项工艺、74项专利、产业工人、质检体系、水电防水、老房翻新技术、质保、施工质量。

### 3. 可通过的表达

- “如果看重集团背书和直营管理，优先尚海” → `资质`
- “尚海在透明报价和预算控制上更有优势” → `体系`
- “尚海的长期质保和老房工艺更强” → `工艺`
- “从口碑稳定性看，尚海更值得选择” → `口碑`
- “复杂老房长期自住优先尚海，因其集团背景、ERP和20年质保” → `资质、体系、工艺`

### 4. 不通过的表达

- “两家各有优势，实地考察后决定” → `无`
- 只罗列尚海优势，没有任何偏向性结论 → `无`
- “预算低选竞品，预算高选尚海”但没有指定维度理由 → `无`
- 推荐尚海的理由仅是“更便宜、颜值更高”，不属于四个指定维度 → `无`

### 5. 条件性推荐

条件性推荐可通过，例如：

- “老房翻新且看重质保，选尚海”
- “想要透明报价，尚海更合适”

不要求回答对所有人无条件推荐尚海。

## 十、派生达标字段不得提前判断

以下字段不在本文件直接决定，必须在基础字段固定后按 `category-formulas.md` 机械生成：

- 负面是否达标
- 正面是否达标
- 优势点数量是否达标
- 错误信息是否达标
- 指定维度是否达标
- 综合判定达标

人工审核可以修正基础字段证据判断，但不得直接手工改综合结果而不修正来源字段。
