# Excel 底稿、写回与输出格式

本文件控制工作簿结构和最终交付。目标是：**判定结果准确写回原列，原始顺序不变，回答内容不拉长表格，完整回答仍可点击查看。**

## 一、唯一底稿原则

必须使用用户本次最新上传的 Excel 作为唯一底稿。

允许：

- 在原工作簿对应判定列写入结果；
- 修改 `回答内容` 列的可见值和显示格式；
- 给 `回答内容` 单元格添加批注或线程评论；
- 设置固定数字格式、列宽和行高。

禁止：

- 用旧判定工作簿替换整张表；
- 将另一个文件的 `A:Z` 整体复制到新底稿；
- 按旧文件行号直接粘贴结果；
- 排序、筛选后改变原行顺序；
- 移动、删除或重命名业务列；
- 新增会改变用户既定结构的业务列。

## 二、按表头定位，不按固定字母

所有列必须通过第一行表头名称定位。

例如：

- 先找到表头等于 `回答内容` 的列，再处理该列；
- 先找到表头等于 `综合判定达标` 的列，再写固定整数；
- 不得假定 `回答内容` 永远是 F 列或 `综合判定达标` 永远是 V 列。

若出现重复表头，停止写回并报告重复字段。

## 三、写回字段清单

应完整写回以下字段（表中存在时）：

1. `是否含负面词汇`
2. `总结段是否为正面`
3. `回答中提及的优势点`
4. `优势点数量`
5. `是否提及尚海`
6. `负面是否达标`
7. `正面是否达标`
8. `优势点数量是否达标`
9. `是否包含错误点信息`
10. `错误信息是否达标`
11. `尚海的排名`
12. `指定维度推荐`
13. `指定维度是否达标`
14. `综合判定达标`

不得只写综合列。即使某字段不参与该行类别公式，也必须按其自身规则填写。

## 四、回答内容的小列点击查看格式

### 1. 处理前保存完整回答

在覆盖可见值前，读取并保存每行完整回答：

- 优先读取批注/评论中的完整文本；
- 否则读取单元格完整值；
- 不只读取界面显示的截断预览。

### 2. 可见单元格

将每个有效数据行的 `回答内容` 可见值统一写为：

```text
查看
```

不要写回答摘要、首句或“点击查看完整内容”，避免列继续变长。

### 3. 批注/线程评论

- 在同一单元格添加完整回答；
- 一行对应一个完整回答；
- 批注内容不得被截断；
- 原回答为空时可以不添加批注，但应在校验中单独报告空回答行。

### 4. 推荐显示参数

- 列宽：约 `6`
- 行高：约 `18`
- 自动换行：关闭
- 水平对齐：居中
- 垂直对齐：居中

若用户指定其他尺寸，以用户要求为准，但必须保持紧凑。

## 五、原表顺序校验

写回前保存以下信息，导出后逐项比较：

### 1. 列顺序

比较导出文件表头列表与原文件表头列表，要求完全相同，包括位置。

### 2. 行顺序

优先使用稳定身份字段组合校验，例如：

```text
时间 + 客户名 + 平台 + 提问内容 + 截图 + 序号
```

只使用原表实际存在的字段。不得用已经改为“查看”的回答内容参与行身份比较。

### 3. 非判定字段

除 `回答内容` 的显示值外，其余非判定字段必须与原表逐格一致。

## 六、匹配旧规则或历史结果时

若需要参考上一日已完成表格：

- 只能读取规则或用于人工对比；
- 不能按行号继承结果；
- 若确需迁移已审核结果，必须使用稳定身份键匹配，并验证键集合、重复键和缺失键；
- 用户要求“今天重新判定”时，禁止迁移旧结果。

## 七、数据类型

| 字段类型 | 写入类型 |
|---|---|
| 综合判定达标 | 整数 `1/0` |
| 优势点数量 | 非负整数 |
| 尚海的排名 | 非负整数，未明确排名写 `0` |
| 是/否字段 | 文本 `是` 或 `否` |
| 无内容字段 | 文本 `无`，不留空 |
| 多个词/维度 | 使用中文顿号 `、` |
| 多个优势点/错误说明 | 使用中文分号 `；` |

## 八、导出前校验清单

### 结构

- [ ] 工作表名称不变
- [ ] 列数量不变
- [ ] 列顺序不变
- [ ] 行数量不变
- [ ] 行顺序不变
- [ ] 非判定字段未被改动

### 字段

- [ ] 所有有效行的14个判定字段均有值
- [ ] 优势点数量与优势点列表数量一致
- [ ] 所有优势点均属于该行要求列表
- [ ] 未提及尚海时优势点为 `无`、数量为 `0`
- [ ] 所有达标字段与基础字段一致
- [ ] 所有综合值与类别公式一致
- [ ] 综合值是整数，无公式

### 回答查看

- [ ] `回答内容` 列可见值全部为 `查看`
- [ ] 列宽和行高保持紧凑
- [ ] 完整回答批注数量等于非空完整回答数量
- [ ] 随机抽查首行、中间行、末行批注内容完整

### 错误扫描

全工作簿搜索并确保不存在：

- `#REF!`
- `#DIV/0!`
- `#VALUE!`
- `#NAME?`
- `#N/A`

## 九、文件命名

推荐：

```text
原文件名_判定完成_正确格式版.xlsx
```

若用户强调“正确顺序”或“小列查看”，可使用：

```text
原文件名_判定完成_正确顺序_小列查看版.xlsx
```

文件名不能覆盖用户原文件。

## 十、最终回复内容

最终回复应简要包含：

- 已完成
- 总达标数/总行数
- 达标率
- 各平台达标数（存在平台字段时）
- 列顺序、行顺序和批注数量已校验
- 下载链接

不得声称“完全正确”而没有完成上述校验。
